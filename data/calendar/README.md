# 发布资料

本目录只保存可进入仓库和发布流程的当前资料。整理过程、原始来源和审查批次位于本机 `.local/calendar-backup-*/`，不作为应用运行时依赖，也不提交 Git。

## 当前内容

- `confirmed/`：当前确认的事件、计划、表演、作品、录播和账号资料。
- `releases/`：发布快照及其清单。
- `inventory.json`：资料范围和文件盘点。

`confirmed/` 是数据库导入的唯一输入。字段中的 `evidence`、来源 URL、BV 号和定位文字是最小可追溯信息，不依赖本仓库保存原始截图或抓取响应。

## 数据边界

资料覆盖 EOE 成员、组合和相关活动。事件、作品、录播和歌曲覆盖以当前确认资料为准，不宣称历史零遗漏。歌曲主要收录已取得明确切片、合集分 P 或多来源曲目资料的作品；没有可靠曲目证据的整场录播不会被推导为完整歌单。

原计划、取消、改期和后续安排分别保留并关联。跨日活动可保存 `endDate`，网络波动重开不拆成新场。录播按 BV 记录，每场保留一个主要可用版本即可。

## 维护规则

修改确认数据时同步更新发布快照或重新生成快照，并运行仓库检查。原始证据、批次报告和人工复核过程只在本地备份中维护；如果某个来源改变了发布结论，只提交修订后的当前数据和必要的来源摘要。
