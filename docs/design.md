# 设计说明

## 定位

Elfofera API 是一份当前可发布的 EOE 时间线、作品和录播资料库。仓库维护当前确认结果和运行代码，不维护整理过程本身。

工具链持续跟随当前版本，接口与调用方一起重构，不保留历史兼容层。错误在实际故障边界暴露，不用猜测值、统一重试或 fallback 掩盖失败。

## 数据来源与边界

事件、计划、表演、作品和录播来自官方文字、公开目录、成员及组合账号、主要录播来源和多来源曲目资料。旧站和工作簿只能作为对照线索，不能替代当前证据。

发布数据保留来源类型、URL、BV 号、日期和必要定位文字。原始图片、批量响应、代理报告、人工校对记录和失败请求保存在本机 `.local/calendar-backup-*/`，不进入仓库或运行时。

确认数据是可发布子集，不承诺历史演出或歌曲逐曲零遗漏。录播每场保留一个主要可用版本；歌曲优先收录明确切片、合集分 P 和多来源清单，不逐条观看长录播枚举。

## 数据关联

- 事件表示直播、活动、发布、公告或计划。
- 计划和实际事件分开保存，取消和改期通过关联表达。
- 表演通过 `eventId` 和 `workId` 关联，不因剪辑、分 P 或跨日重复计数。
- 作品使用稳定 ID；同名不同作品不合并。
- 录播使用 BV 作为视频身份，来源账号不等于完整参与者名单。

## 第一版边界

数据库第一版覆盖当前确认数据，导入脚本默认导入 2022-07 至 2023-12 的首批范围；后续年份的数据文件可继续扩展导入范围。API 先提供只读查询，不实现自动采集、定时任务或生产部署。

## 本地资料备份

`.local/calendar-backup-*/` 是研究资料的本地备份目录，包含 evidence、候选、来源快照和 reviews。它不是仓库接口，也不是发布构建输入；需要修订数据时，在本地查证后只提交最终确认结果及最小来源摘要。
