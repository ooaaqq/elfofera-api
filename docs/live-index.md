# EOE LIVE INDEX

## 当前视觉方向

瑞典杂志式满屏拼版：成员色块、黑白灰界面、克制字号、严格网格、矩形无缝连接。页面使用 100dvh，外边距和模块间距均为 0。不使用品牌导航、Hero、统计、页脚或重复区域标签。

桌面左侧约占三分之二：页面最顶部是 8px 高、横向铺满视口的五段无文字成员色带，下方为 40px 高、同一行的年份选择与 01–12 文字月份导航，再下方为单月日历。右侧为日期与直播标题、当前事件详情与可内部滚动的完整歌单。成员色带承担身份信息，左侧日历与右侧详情从色带下方开始，名称通过无障碍标签保留，黑白灰承担选中与层级，其余控件使用文字、留白和对齐区分层级。

浅色成员底色是成员色的低饱和展示变体；选中仍使用固定 Deep 色。成员之外的界面使用白底、黑字、灰色悬停和黑底白字选中态。日历与详情使用同一白底，左右分割线由整个左栏单独绘制，连续覆盖成员、年月导航和日历；日期最后一列与详情不重复画边框。年份与月份使用纯文字索引，当前月份以小圆点标记；年份选项从年份下方展开，不覆盖月份；日期使用七列网格，按当月实际周数均分剩余高度；首尾补齐空白格，每格保留底边与右边框。

## 交互与响应式

- 默认展示全部成员；点击成员筛选，再次点击同一成员恢复全部，不设“全部”按钮。年份仅常驻当前值，鼠标悬停或点击后从年份下方展开纵向文字选项；支持键盘 Tab 选择、Escape 关闭和点击外部关闭。
- 默认选择当前年份最近直播所在月份；切换年份选择该年最近直播月份，切换成员保留月份。空月份显示空详情，不跨月补选。
- 点击月份直接切换单月；日期格直接承担直播选择：有多场的日期显示场次编号，点击编号切换事件；右侧仅展示当前事件详情。日期仅显示数字和成员色短线，场次数保留在无障碍标签中。不提供搜索、全年日期总览和前后翻页控件。
- 歌单显示作品、原唱、演唱成员和表演形式，录播链接在详情标题区域。
- 歌单一次渲染全部曲目，只在歌单区域纵向滚动；日期、标题与场次固定，页面不滚动。
- ≤700px 成员色带高 40px、年月导航高 44px，年份与月份保持同一行，缩小字号和内边距；选择日期后进入整屏详情，返回按钮或 Escape 回到日历。
- 使用随应用提供的 Inter 与系统中文无衬线字体。直角控件、无阴影，只有颜色过渡。

## 数据

前端由确认文件生成静态展示数据，不读取本地 evidence。日期与表演使用现有关联，作品以 ID 识别；未知分类不展示。节目系列仍为待实现的独立筛选维度，不替代标题和内容分类。

年份数据按需加载并在内存缓存。切换年份时只采纳最后一次选择的响应，成功后同步更新年份、日历与详情；加载过程中暂停日期、月份和成员操作。请求超时或失败时显示明确提示，保留已载入的年份，用户重新选择年份可再次加载，不自动重试。

数据由构建脚本生成到 `frontend/public/data/`，随 Vite 构建自动复制到发布目录，开发和生产均使用 `/data/` 路径。带 hash 的静态资源可长期缓存，HTML 和未带 hash 的数据 JSON 应重新验证；服务器缓存配置由 fleet 维护。
